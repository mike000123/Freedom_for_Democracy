# Freedom for Democracy – πρωτότυπο MVP

Πρωτότυπο της πλατφόρμας που δίνει ισότιμη έκθεση σε νέα κόμματα και ένα δομημένο χώρο συζήτησης για τους πολίτες. Βασίζεται στο έγγραφο «Σχέδιο MVP».

**Στοίβα:** Django 5 · SQLite (τοπικά) ή PostgreSQL · σελίδες από τον server, χωρίς JavaScript.

## Εκκίνηση χωρίς cmd (Windows)

Διπλό κλικ στο **`start.bat`**. Την πρώτη φορά φτιάχνει περιβάλλον και εγκαθιστά τα απαραίτητα (θέλει λίγα λεπτά και internet). Ο server τρέχει στο παρασκήνιο (χωρίς μαύρο παράθυρο) και ανοίγει ο browser στη διεύθυνση που τυπώνεται, κανονικά http://127.0.0.1:8010/. Αν η θύρα 8010 είναι πιασμένη, επιλέγεται η επόμενη ελεύθερη έως 8030. Για να σταματήσει: διπλό κλικ στο **`stop.bat`**. Τα μηνύματα του server γράφονται στο `launcher.log` (μην το μοιράζεστε).

Τοπικοί λογαριασμοί (μόνο για δοκιμή, δημιουργούνται αυτόματα):

| Ρόλος | Διεύθυνση | Στοιχεία |
|---|---|---|
| Διαχειριστής | /admin/ | `admin` / `admin` (αλλάζει με `FD_ADMIN_PASSWORD`) |
| Εκπρόσωπος κόμματος | /eisodos/ | `demo@example.org` / `demo-kodikos-1` |

Στην πρώτη είσοδο εκπροσώπου εμφανίζεται κλειδί 2FA. Βάλτε το χειροκίνητα σε εφαρμογή ταυτοποίησης (Google Authenticator, Aegis, Microsoft Authenticator) και γράψτε τον 6ψήφιο κωδικό.

## Λογαριασμοί κομμάτων

- Ο διαχειριστής προσκαλεί: `python manage.py invite_member email@κομματος.gr "Ακριβές όνομα κόμματος"`. Τυπώνεται προσωρινός κωδικός που στέλνεται με ασφαλή τρόπο.
- Είσοδος με κωδικό και 2FA (TOTP). Μέχρι 3 μέλη ανά κόμμα. Χαμένο 2FA: ενέργεια «Επαναφορά δεύτερου παράγοντα» στο admin, στη λίστα PartyMember.
- Το κόμμα αλλάζει μόνο σύνθημα, έτος ίδρυσης, ιδρυτές, χρηματοδότηση, ιστοσελίδα και τις προτάσεις του. Υπεύθυνα πρόσωπα, κατηγορία, βαθμίδα και δημοσίευση ελέγχονται από τον διαχειριστή.
- Κάθε αλλαγή καταγράφεται δημόσια στο ιστορικό του κόμματος. Οι επίσημες απαντήσεις φέρουν το όνομα του κόμματος.

## Ροή εργασίας διαχειριστή

1. Διαχείριση → **Κόμματα και ομάδες** → δημιουργία. Το κόμμα είναι αρχικά μη δημοσιευμένο.
2. Αφού ελεγχθούν οι προϋποθέσεις, τσεκάρετε «Δημοσιευμένο» και συμπληρώστε την αιτιολόγηση. Η απόφαση καταγράφεται αυτόματα στο δημόσιο αρχείο.
3. Προσθέστε **Δομημένες προτάσεις**. Αν το κόμμα εισέλθει στη Βουλή, τσεκάρετε «Απόφοιτο»: βγαίνει από την εναλλαγή.
4. Για αφαίρεση σχολίου: τσεκάρετε «Αφαιρέθηκε» και γράψτε αιτιολόγηση (δημοσιεύεται).

## Τακτική συντήρηση

`python manage.py purge_old` διαγράφει τα κατακερματισμένα αναγνωριστικά ρυθμού που ξεπέρασαν τις 24 ώρες (ρύθμιση `FD_IP_RETENTION_HOURS`). Να προγραμματιστεί π.χ. κάθε ώρα.

## Ρυθμίσεις (μεταβλητές περιβάλλοντος)

| Μεταβλητή | Σκοπός |
|---|---|
| `FD_SECRET_KEY`, `FD_IP_HASH_KEY` | Μυστικά κλειδιά. **Αλλάξτε τα** πριν από κάθε πραγματική χρήση. |
| `FD_DEBUG=0` | Παραγωγή (ενεργοποιεί ασφαλή cookies και HTTPS). |
| `FD_ALLOWED_HOSTS` | Λίστα domain, χωρισμένη με κόμμα. |
| `FD_DEMO_BANNER=0` | Κρύβει το πορτοκαλί banner δοκιμαστικής έκδοσης. |
| `FD_DB=postgres` και `FD_DB_*` | Χρήση PostgreSQL (απαιτεί `pip install "psycopg[binary]"`). |

Οι αριθμοί εναλλαγής και τα όρια ρυθμού βρίσκονται στο τέλος του `fd_site/settings.py`.

## Γνωστά κενά πριν από πραγματική χρήση

- **Captcha:** το τωρινό είναι πρόσθεση, μόνο για δοκιμή. Να αντικατασταθεί από πάροχο συμβατό με GDPR (η διεπαφή είναι στο `core/captcha.py`).
- **Λογαριασμοί κομμάτων:** υπάρχει είσοδος με 2FA. Λείπουν: αποστολή email (πρόσκληση, επαναφορά κωδικού), κρυπτογράφηση του κλειδιού TOTP στη βάση και 2FA στο Django admin.
- **Προαιρετικός λογαριασμός πολίτη** (ψευδώνυμο και επιβεβαιωμένο email): δεν έχει υλοποιηθεί. Απαιτεί πρώτα νομικό έλεγχο GDPR.
- **Επαλήθευση υπεύθυνων προσώπων:** γίνεται χειροκίνητα (υπεύθυνη δήλωση gov.gr). Δεν υπάρχει ανέβασμα εγγράφων.
- **Μέτρηση εμφανίσεων:** μετράει κάθε φόρτωση της αρχικής (GET). Σε παραγωγή πρέπει να αποκλειστούν bots, αλλιώς παραμορφώνεται η εναλλαγή.
- **Reverse proxy:** το όριο ρυθμού διαβάζει το `REMOTE_ADDR`. Πίσω από proxy θέλει σωστή ρύθμιση.
- **Ασφάλεια:** λείπουν πολιτική περιεχομένου (CSP), αντίγραφα ασφαλείας και διαδικασία αναφοράς τρωτοτήτων.
- **Νομικά:** κείμενα απορρήτου, υπεύθυνος επεξεργασίας και ο ορισμός του «νέου κόμματος» χρειάζονται νομικό έλεγχο.
- **Εκτός πρωτοτύπου (επόμενες φάσεις):** ερωτηματολόγιο, σύγκριση θέσεων, ολοκληρωμένες προτάσεις πολιτών, επαλήθευση πολιτών.
- Όλα τα δεδομένα του `seed_demo` είναι φανταστικά.

## Email λογαριασμών

Τοπικά τα email δεν στέλνονται: τυπώνονται στο `launcher.log` (εκεί βρίσκεις τον σύνδεσμο επιβεβαίωσης για δοκιμή· μην μοιραστείς το αρχείο). Για πραγματική αποστολή όρισε `FD_EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend` και `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `EMAIL_USE_TLS=1`, `FD_FROM_EMAIL`. Η σελίδα `/aporrito/` είναι πρόχειρη και θέλει συμπλήρωση στοιχείων υπευθύνου επεξεργασίας και νομικό έλεγχο.
