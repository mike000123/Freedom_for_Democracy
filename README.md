# Freedom for Democracy — έκδοση Supabase

Στατικό site (React + Vite) που μιλά απευθείας με το Supabase. Δείτε το `SUPABASE_PLAN.md` για το σχέδιο.

## Βάση δεδομένων (Supabase → SQL Editor, με τη σειρά)
1. `db/001_schema.sql` — πίνακες, κανόνες πρόσβασης (RLS), συναρτήσεις
2. `db/002_functions.sql` — στατιστικά για τη σελίδα Διαφάνεια
3. `db/003_seed_demo.sql` — φανταστικά δεδομένα δείγματος (προαιρετικό, με σήμανση «Παράδειγμα»)

## Τοπική εκτέλεση
Χρειάζεται Node.js 18 ή νεότερο.
```
npm install
npm run dev        # http://localhost:5173
npm run build      # δημιουργεί τον φάκελο dist
```
Τα στοιχεία σύνδεσης είναι στο `src/config.js` (μόνο το δημόσιο anon key).

## Τι υπάρχει ως τώρα (στάδιο 3, μόνο ανάγνωση)
Αρχική με στατιστικά, κόμματα και ομάδες (ισότιμη εναλλαγή μέσω `pick_parties`), προφίλ κόμματος, θέματα,
προτάσεις, ερωτήματα και σχόλια (ανάγνωση), κανόνες, διαφάνεια.
Δεν υπάρχουν ακόμη: σύνδεση/εγγραφή, υποβολή σχολίων, πίνακας κομμάτων, διαχείριση, chat.

## Ασφάλεια
Μην βάλεις ποτέ στο repo το `service_role` ή το Secret key του Supabase.
